
# Chronicle of Černobor

*“The truth is often hidden between the lines.”*

**Chronicle of Černobor** is a fan-made web archive dedicated to the world of the Černobor LARP. The project is presented as a library and collection of historical records compiled by **Dalimila Hájková**, a chronicler from Zelená Hora documenting events and happenings around Kaltwasser.

The archive brings together chronicles, documents, maps, and other records that help preserve and explore the history of Černobor.

## What's Inside the Archive?

- **Chronicles and Historical Records** — events, stories, and accounts from the past.
- **Archived Documents** — manuscripts, notes, and other collected materials.
- **Liber Magicae** — records concerning magic and its mysteries.
- **Clavis ad miraculum cognitionis** — a document dedicated to knowledge and its mysteries.
- **Properties of Known Substances** — a collection of known materials and their properties.
- **Maps and Other Sources** — resources to help navigate the world of Černobor.

The archive may expand over time with new entries, documents, and discoveries.

## Project Aesthetic

The website is designed to resemble an ancient library or archive, reflecting the fantasy atmosphere of the world of Černobor.

Its visual style primarily features:

- Dark forest tones.
- An aged parchment aesthetic.
- Serif typography.
- Motifs inspired by books, chronicles, and historical documents.

The archive is presented from the perspective of its chronicler. Individual records may therefore reflect her personal views, the information available to her, and uncertainties found in surviving sources.

## Technologies

The project is built using standard web technologies:

- **HTML5** — page structure and content.
- **CSS3** — styling, layout, and visual presentation.
- **JavaScript** — interactive elements and dynamic functionality.
- **JSON** — storing and processing selected data.

The project does not rely on a large frontend framework.

## Getting Started

### Running Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/leafaANDROMEDA/kronika-cernobor.git
   ```

2. Open the project directory.

3. Open `index.html` in your web browser.

For a more convenient development experience, you can use an extension such as **Live Server** in Visual Studio Code.

### Online Access

If the project is published through GitHub Pages, it can also be accessed directly through a web browser.
